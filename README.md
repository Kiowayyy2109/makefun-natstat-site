**Nusantara in Figures** — a national statistics site for Indonesia, designed like a broadsheet front page crossed with a statistical yearbook. Four linked pages (Overview, Population, Economy, People & Welfare) carry real published BPS figures, each labelled with its period: 281.6 million people, Rp 22,139 trillion of GDP, 1.57% inflation, a poverty rate at a record-low 8.47%. Every chart is drawn in-page from the series printed beside it; the site is plain static files under `app/` — no build step, no network, works on desktop and phone.

## Run it

```sh
node serve.ts           # serve app/ locally
node main.ts            # hand it in: copies app/ + screenshots/ and writes the dossier
```
